Project: Digital Trial Room — Kiosk UI Redesign

Redesign my existing Saree Virtual Try-On POC into a polished, production-style touchscreen experience called Digital Trial Room.

I have already implemented the logical functionality and prepared the design reference images inside the project. Your job is to redesign the existing UI to match these references closely while preserving all working functionality.

1. Read and Follow the Design References

Before making any changes, inspect the following reference images. These are the primary visual specifications for each screen.

Step 1 — Choose Saree
references/design reference/step-1/Premium Saree Virtual Try-On Kiosk-1.png

Follow this reference for the initial saree-selection screen. Customers should browse sarees, view one design prominently at a time, swipe between products, and select one or multiple sarees.

Step 2 — Customer Photo Capture
references/design reference/step-2/Virtual Saree Try-On Countdown.png

Follow this reference for the photo-capture interface. The customer should be able to position themselves for a full-body photo, with a large, highly visible five-second countdown displayed centrally before the picture is captured.

Step 3 — Virtual Try-On Results
references/design reference/step-3/a_polished_vertical_touchscreen_kiosk_ui_poster.png

Follow this reference for the final virtual try-on screen. Display the customer's try-on result prominently, with selected sarees available in a thumbnail panel. Selecting a thumbnail should switch the displayed saree.

Do not introduce left/right directional buttons, front/side/back view selectors, zoom buttons, comparison controls, or unrelated features that are absent from the intended design.
